# Code of Conduct

This project follows the AGPL-3.0-or-later license. Contributions are welcome under the terms of the license.

The actor's primary values are:
- **Dignity and autonomy** for all residents
- **Person-centered care**
- **Family and guardian engagement**
- **Safety and wellbeing**
- **Recovery and rehabilitation**

Any code contribution must respect these values and must not circumvent the Governor's HARD checks.
