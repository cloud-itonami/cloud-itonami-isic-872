# Security

This actor handles sensitive data related to individuals with mental health, intellectual disability, and substance use conditions. The Governor's three HARD checks are permanent, un-overridable safeguards:

1. **Resident verification** — all proposals require a verified resident record
2. **Effect restriction** — all operations must be `:propose` only, never direct action
3. **Scope exclusion** — medication, clinical diagnosis, care-plan changes, restraint, guardianship, disciplinary, end-of-life, and safety-authority decisions are permanently blocked

These checks cannot be overridden or disabled.

Report security concerns to the repository maintainer.
